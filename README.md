# Beyond the Observable

A responsive Flask-powered astrophysics publication website.

## Run locally
1. Install Python 3.10 or newer.
2. In a terminal, enter this project folder.
3. Run `pip install -r requirements.txt`.
4. Run `python app.py`.
5. Open http://127.0.0.1:5000.

## Pages
- `/` — homepage
- `/article/black-holes` — black-hole feature
- `/article/asteroseismology` — asteroseismology
- `/article/gravitational-waves` — gravitational waves
- `/about` — about the publication

## Before publishing
Review and fact-check article content and references. The cosmic artwork is CSS illustration, not an astronomical observation. The newsletter form is a visual demo and is not connected to an email service. Use a production WSGI server and set debug off before deployment.
